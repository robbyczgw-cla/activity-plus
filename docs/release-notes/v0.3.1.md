Activity+ now speaks your Mac's language.

**Languages**
- The app follows the language set in System Settings: English, German, French, Spanish, Italian, Portuguese (Brazil), Japanese or Simplified Chinese
- Where possible, terms follow Apple's own Activity Monitor in each language, so memory, energy and process names read the way macOS uses them
- Numbers use your region's format, for example 25,7 GB with a decimal comma. The command line tool and the MCP server keep machine-readable numbers

**Known gaps**
- Short durations such as "20d 2h" are still abbreviated in English
- Alerts recorded before the update stay in the language they were written in

The translations were made with AI help and checked for placeholders, plural forms and layout. Native speakers have not reviewed French, Spanish, Italian, Portuguese, Japanese and Chinese yet, so corrections are welcome as GitHub issues.

Requires macOS 15 or later on Apple silicon. Notarized by Apple.
