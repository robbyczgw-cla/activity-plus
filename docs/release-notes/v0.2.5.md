Trace a spike back to the process behind it.

**New**
- The history now keeps the busiest child processes of each app (every 5 minutes), so a spike in "Terminal" shows it was `node vite` or `cargo build`. Point at the history chart to see who was busy at that moment, or expand an app in "Apps that used the most"
- Alerts name the process when an app has several: "Terminal is keeping the CPU busy … Mostly node vite (pid 4312)"
- Recording sessions show the main process of each app
- `aplus mcp`: the history tool lists the processes behind the top apps and answers "what was busy around 14:30?"

**Privacy**
Command lines are shortened to the program and its first arguments; anything that looks like a token, password, key or credential in a URL is blanked before it is stored. It stays on your Mac, like the rest of the history.

Requires macOS 15 or later on Apple silicon. Notarized by Apple.
