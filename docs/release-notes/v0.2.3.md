Safety and accuracy release, after an independent code review.

**Safer**
- Uninstall only ever touches folders directly inside your Library, and leaves folders that another installed app also uses
- Quit and Force Quit check that the process is still the one you saw, and only quit the copy of an app you picked
- "Stop idle dev servers" counts only the idle time Activity+ has actually watched
- Turning a startup item on now asks first, like turning it off; turning one off also works when it is not loaded right now
- Your public IP is looked up only at api.ipify.org, exactly as the privacy notes say

**More accurate**
- History totals weight each sample by the time it covers, and a sample right after sleep no longer counts the whole night
- Disk throughput is counted per drive, so drives that come and go cannot cause spikes
- The code signature check in the process inspector also verifies the program code
- Muting an app also covers audio processes it starts later (beta)
- History older than 30 days is removed daily, not only at launch

Requires macOS 15 or later on Apple silicon. Notarized by Apple.
